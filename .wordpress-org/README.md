# wordpress.org assets

Not shipped in the plugin ZIP (see `.distignore`) — these are committed to the
`assets/` directory of the wordpress.org SVN repo, and reused as the GitHub
README header.

| File | Size | Use |
| --- | --- | --- |
| `banner-1544x500.png` | 1544×500 | Plugin page header (retina) + GitHub README header |
| `banner-772x250.png` | 772×250 | Plugin page header (standard) |
| `icon-256x256.png` | 256×256 | Search results and plugin card (retina) |
| `icon-128x128.png` | 128×128 | Search results and plugin card |
| `screenshot-1.png` … `screenshot-5.png` | — | Captions live in `readme.txt` under `== Screenshots ==`, in order |

wordpress.org overlays the plugin name and author over the lower-left of the
banner, so keep that corner visually quiet and free of text.
